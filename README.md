# powermeross

Mac のバッテリー残量に応じて、Meross 製スマートプラグの電源を自動でオン/オフするスクリプトです。

## 動作概要

`m2_onoff.py` を実行すると以下の処理を行います。

1. 実行時刻から、オン/オフのしきい値を決定します（後述）。
2. `pmset -g batt` の出力から Mac のバッテリー残量を取得します。
3. バッテリー残量としきい値を比較して Meross スマートプラグを制御します。
   - 残量が **オンしきい値以下** → プラグをオン（充電開始）
   - 残量が **オフしきい値以上** → プラグをオフ（充電停止）
   - その中間 → 何もしない（プラグの状態を維持）

> **Note:** 自宅ネットワーク（`192.168.1.0/24`）判定はVPN接続時に誤判定するため、現在 [m2_onoff.py](m2_onoff.py) 内でコメントアウトして無効化しています。そのため現状はネットワークに関わらず常にバッテリー残量で判定します。

### 時間帯別のしきい値

| 時間帯 | オンしきい値 | オフしきい値 |
| --- | --- | --- |
| 2:00〜4:59（深夜帯） | 20% | 100% |
| 上記以外（通常帯） | 20% | 70% |

同じプラグを **2:00 にオン、5:00 にオフする別プログラム**が動いています。深夜帯のオフしきい値を通常どおり 70% にすると、別プログラムによる充電を 70% で打ち消してしまうため、この時間帯は 100% になるまでオフにしません。

一方でオンしきい値は 20% のまま残してあります。これにより、別プログラムが動いていない場合でもバッテリー残量が 20% 以下になれば本スクリプトが充電を開始します。

macOS の `pmset` コマンドに依存しているため、macOS 環境での実行を想定しています。

## 必要要件

- Python 3
- [meross-iot](https://pypi.org/project/meross-iot/)（`requirements.txt` に記載）

```bash
pip install -r requirements.txt
```

## 環境変数

実行前に以下の環境変数を設定してください。

| 変数名 | 説明 |
| --- | --- |
| `MEROSS_UID` | Meross アカウントのメールアドレス |
| `MEROSS_PID` | Meross アカウントのパスワード |
| `MEROSS_TID` | 制御対象デバイスの UUID |

```bash
export MEROSS_UID="your-email@example.com"
export MEROSS_PID="your-password"
export MEROSS_TID="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

## 実行方法

```bash
python m2_onoff.py
```

`cron` や `launchd` などで定期実行することで、バッテリー残量に応じた充電の自動オン/オフを実現できます。実運用では `launchd`（`~/Library/LaunchAgents/`）から1時間に3回（毎時12分・32分・52分）起動しています。

## ログ

`logging` を使用し、すべて標準出力（stdout）に日時付きで出力します。

```
2026-09-24 16:18:18 [INFO] バッテリー残量: 18%
2026-09-24 16:18:18 [INFO] M02 C402: OFF -> ON
2026-09-24 16:18:18 [WARNING] デバイスが見つかりません
```

| レベル | 用途 |
| --- | --- |
| `INFO` | 正常実行時のメッセージ（残量、プラグの状態変化など） |
| `WARNING` | 対象デバイスが見つからない場合 |

`meross-iot` ライブラリ自身が出力する `INFO` / `WARNING` はノイズになるため、ライブラリのロガー（`meross_iot`）は `ERROR` 以上のみ通すよう抑制しています。

`launchd` の `StandardOutPath` / `StandardErrorPath` でファイルに保存する運用のため、本スクリプト側ではログファイルの管理（出力先やローテーション）は行いません。

## 注意事項

- `HOME_NET`（`192.168.1.0/24`）、バッテリーのしきい値、対象外の時間帯はスクリプト内にハードコードされているため、環境に合わせて書き換えてください。
- Meross アカウントの認証情報は環境変数で渡す前提のため、`.env` ファイルや IDE の実行構成（`.vscode/launch.json` など）に直接書く場合は、必ず Git 管理対象から除外してください。
